Сохранить новое место

Для сохранения точки не там, где ты стоишь, зажми место на карте пальцем примерно на секунду. На компьютере можно нажать правой кнопкой.

GPS-кнопка сохраняет текущую позицию. Кнопка “Сохранить выбранную точку” сохраняет координаты, выбранные долгим нажатием на карте.

Участники группы

не в группе моя позиция скрыта

Переход по приглашению открывает группу локально: имя и последняя группа запоминаются на этом телефоне, а синхронизация с Supabase догоняет при связи. Точка на карте появляется только после кнопки “Начать показ моей позиции”.

Локальный человек будет запомнен на этом устройстве.

Для live-режима нужен Supabase URL и anon public key в файле config.js.

Чат группы

чат недоступен последние 50

Сообщения видны всем, кто знает ID группы. Точки из чата показываются кликабельными карточками: нажми карточку, чтобы перейти к точке на карте. В этом MVP правка и удаление своих сообщений определяются по локальному user_id этого браузера.

Чат появится после входа в группу.

Как установить

iPhone: открой ссылку в Safari → Поделиться → На экран «Домой».

Android: открой ссылку в Chrome → меню ⋮ → Установить приложение.
